# Vue vs Angular Prototype

## Purpose
This repository contains two small prototype applications built with **Vue** and **Angular**.  
The goal was to gain practical experience with both frameworks in order to determine which one would be more suitable for the main project.

The detailed reasoning and comparison can be found in the portfolio.

---

## Prototype Application
Both prototypes implement the same small **Marathon App** with the following functionality:

- Permanent **navbar**
- **Marathon list** (GET request)
- **Marathon detail page** (dynamic route)
- **Training plan overview** per marathon
- **Form to add a training session** (POST request)
- Basic styling

A **json-server** with dummy data was used to simulate a backend API and allow realistic API calls.

---

## Result
After building both prototypes, **Vue** was chosen as the frontend framework for the main project.
